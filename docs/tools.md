# 工具实现

12 个工具都实现 `Tool`（契约与落盘规范见 AGENTS.md 3.2 / 3.3），区别只在
`ToolOptions` 的变体与 `execute` 内部。本文记录各工具的实现要点与已知限制。

## 共同管线

1. `validate` 只读预检：解析页码、检查输入数量与扩展名，尽早失败。
2. 循环体内每步 `check_cancel(cancel)?` + `progress.report(fraction, msg)`。
3. 先用 `pdf_io::resolve_outputs(&paths, req.conflict)` 将本次要写的全部路径解析为最终路径，
   然后写入；不允许先落盘后询问。
4. 统一经 `pdf_io::save_document` / `write_file` 落盘：先写同目录临时文件再 `rename`，
   写前复核目标是否仍然不存在（规划与落盘之间可能隔几分钟渲染）。
5. 落盘后重新打开产物做断言（`validate::assert_page_count` 等）；断言失败时删除产物并
   返回 `ValidationFailed`。

部分失败必须携带 `outputs` 返回 `ToolError::PartialSuccess`，否则已产出的文件会被显示为
整体失败。

## 图片 → PDF（`tools/image_embed.rs`、`image_to_pdf.rs`）

- **JPEG 直通**：以 `DCTDecode` 原样嵌入，不二次编码，画质与体积都最优。
- **PNG 内嵌**：解码后以 `FlateDecode` + `SMask` 写入，透明通道保留。
- **EXIF 方向**：`read_exif_orientation` 读到 5~8 时交换宽高，并通过 `rotate_cw_code`
  合成旋转矩阵。EXIF 旋转与自动旋转必须复合，不得相互覆盖，否则出现重复旋转或漏转。
- **页面排版**：A4 + 统一页边距，等比缩放居中。
- **自动旋转**：图片方向与页面方向冲突时旋转 90° 铺满页面，而非缩为窄条。
- **两图一页**：一个页面开两个槽位，按 A4 横版（左右并排）或竖版（上下并排）计算槽位
  与缩放；每张图独立做方向判定。

## 批量转换（`tools/folder_to_pdf.rs`）

- **数字感知排序**：文件名里的数字按数值比较（`1, 2, 10` 而不是 `1, 10, 2`）；无法
  提取数字的按系统列举顺序稳定排在末尾。
- **输出命名**：`<文件夹名>.pdf` 写回文件夹自身；指定输出目录时重名加 `-2`、`-3`。
- **两图一页**：默认顺序两两配对；勾选「指定合并序号」后只在给定序号对之间合并
  （如 `1-2,5-6`），其余单独成页。
- **方向属于整份文档**：两图一页的 A4 方向不是每页各自决定。单图页（奇数尾页、被排除的
  图片）与合并页共用同一方向与外边距；`PagePolicy` 在写第一页之前定一次，落盘后用
  `assert_page_orientation` 断言全书一致，缺一页即判失败。
- **页码语义**：合并页按输出 PDF 的实际页序连续编号（预览标签即最终页码），图片编号
  另在悬停提示里给出。
- **容错**：单个文件夹失败不中断整批，最后以 `PartialSuccess` 汇报；空文件夹跳过，
  非图片文件忽略。

## 文本水印（`tools/text_watermark.rs`）

根因：PDF 简单字体为单字节 WinAnsi 编码，中文写入后会变成 `?`。当前方案不使用 PDF 文字对象，
而是将文字栅格化为图像：

1. 用系统 TrueType 字体（`engine::ttf`，支持 `.ttc` 集合）取字形轮廓；
2. 以 4× 超采样光栅化为灰度覆盖图，合成「纯色 tint + SMask 透明度」位图；
3. 作为图片 XObject 叠加到页面，保留字号、颜色、透明度、旋转角与平铺/居中策略；
4. 找不到可用中文字体时明确报错，不允许静默输出空白水印。

代价是水印不可选中、不可检索；收益是任意中文与符号均可正确显示。

## 图片水印（`tools/image_watermark.rs`）

读入一张图片，按目标尺寸等比缩放，按设定透明度与位置叠加到每页；覆盖层与页面内容
同属一页内容流，导出与预览一致。

## 合并 / 拆分 / 旋转 / 删页 / 重排 / 提取

六者都是页树操作，共用同一套语义：

- 页码一律按 1 起算，解析集中在 `tools/mod.rs` 的页码解析（合并页与页码的映射见
  `preview_page_numbers`）。
- 重排与提取都以 `tools::reorder::ordered_pages` 的映射为准，预览与产物共用这一个函数，
  避免「预览显示的页序」与「导出的页序」两套实现漂移。
- 输出页数由 `validate::assert_page_count` 复核，`/Rotate` 累加后不超过 360 的整数倍。

## 加密 / 解密（`tools/encrypt.rs`）

基于 `lopdf` 的 AES-256：用户密码（打开）与所有者密码（权限）分离，权限位
（打印 / 复制 / 修改）可组合；解密时用用户密码重写为无加密文档。未加密的 PDF 走解密
会明确报「文件未加密，无需解密」，而不是索要一个不存在的密码。

## PDF → 图片（`tools/pdf_to_image.rs`）

逐页调用 `engine::render`，按 DPI 输出 PNG / JPEG。渲染细节与覆盖率见
[rendering.md](./rendering.md)。

## 已知缺口

- 文本水印是位图，不可选中、不可检索，屏幕阅读器读不到。
- 图片水印对 `/Rotate` 90 / 270 的页面按视觉尺寸定位，个别查看器里可能有几个像素偏移。
- 加密只覆盖 AES-256；数字签名、表单填写、权限降级的细粒度控制均未实现。
- 页面级操作不做内容流优化：删除 / 提取后未引用的对象仍保留在文件中，体积不会随之减小。
