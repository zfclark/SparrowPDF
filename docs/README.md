# 技术文档

面向实现的技术说明：改代码前读对应主题即可，不必通读。

工程规范（提交格式、质量门、分层硬约束、发布流程）在根目录 [AGENTS.md](../AGENTS.md)，
这里只讲**怎么实现的、为什么这么做、哪些输入会出问题**。

| 文档                               | 内容                                                                     |
| ---------------------------------- | ------------------------------------------------------------------------ |
| [architecture.md](./architecture.md) | 分层与依赖方向、模块职责、一次任务的调用链、平台集成（日志 / 清单 / 签名） |
| [tools.md](./tools.md)               | 工具实现：图片嵌入与排版、批量转换、文本与图片水印、加密，以及落盘与自校验 |
| [rendering.md](./rendering.md)       | 内置光栅器：算子覆盖、取字与字形来源、图像解码、矩阵合成、缩略图预览     |
| [ui.md](./ui.md)                     | 应用壳：布局契约、任务状态机、同名文件对话框、主题与拖放                 |

各篇末尾有「已知缺口」，写清哪些输入会产出不完整结果。改渲染或导出前先看那一节，
避免把「本来就不支持」当成回归缺陷排查。
